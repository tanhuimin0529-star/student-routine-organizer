# Section 13 — Milestones

---

## Week 1 — Planning & Foundation

**Focus:** Architecture, documentation, database design, auth system.

### Expected Deliverables

- [ ] GitHub repository created with complete folder structure.
- [ ] `README.md`, `LICENSE`, `.gitignore` committed to `main`.
- [ ] All planning documentation committed to `docs/`.
- [ ] Database schema described and documented.
- [ ] ER Diagram draft created.
- [ ] `feature/authentication` branch created.
- [ ] `config/` and `includes/` files implemented.
- [ ] Authentication system (register, login, logout, session) implemented and locally tested.
- [ ] Dashboard index page functional for a logged-in student.

**Success Criteria:** A student can register, log in, see the dashboard, and log out securely.

---

## Week 2 — Module Development (Sprints)

**Focus:** Exercise Tracker (Member 2), Diary Journal and Money Tracker (Member 3), Habit Tracker start (Member 4).

### Expected Deliverables

- [ ] `feature/exercise` branch merged into `develop`.
- [ ] `feature/diary` branch merged into `develop`.
- [ ] `feature/money` branch merged into `develop`.
- [ ] `feature/habit` branch in progress (check-in logic underway).
- [ ] All merged modules pass basic CRUD testing on `develop`.
- [ ] First merge from `develop` to `main` (tagged `v0.1.0`).

**Success Criteria:** Three of four modules are fully functional on `develop`. Students can log exercise, write diary entries, and record money transactions.

---

## Week 3 — Completion & Admin

**Focus:** Habit Tracker completion, Admin Dashboard, integration, initial bug fixing.

### Expected Deliverables

- [ ] `feature/habit` branch merged into `develop`.
- [ ] `feature/admin` branch merged into `develop`.
- [ ] All four modules integrated and accessible from the student dashboard.
- [ ] Admin can log in, view all users, deactivate, and delete accounts.
- [ ] Cross-module integration testing completed.
- [ ] Test cases documented for each module.
- [ ] All known bugs from integration logged in GitHub Issues.

**Success Criteria:** The complete system is functional on `develop`. All modules accessible, tested, and connected to the shared user session.

---

## Week 4 — Testing, Documentation & Submission

**Focus:** User Acceptance Testing, final documentation, project report, submission.

### Expected Deliverables

- [ ] All bug issues from Week 3 resolved and PRs merged to `develop`.
- [ ] User Acceptance Testing (UAT) completed with simulated student scenarios.
- [ ] `docs/` folder fully populated including screenshots.
- [ ] `docs/report_draft.md` completed.
- [ ] `docs/final_report.md` finalized and formatted.
- [ ] `README.md` reviewed and finalized.
- [ ] Final merge from `develop` to `main` (tagged `v1.0.0`).
- [ ] Repository submitted as the final deliverable.

**Success Criteria:** The repository is submission-ready with all code, documentation, and a clean `main` branch tagged `v1.0.0`.
